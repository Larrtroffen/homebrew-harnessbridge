# Homebrew tap for HarnessBridge

```bash
brew tap Larrtroffen/harnessbridge
brew trust Larrtroffen/harnessbridge   # Homebrew 7 requires explicit trust for third-party taps
brew install --cask harnessbridge
```

Upgrade with `brew upgrade --cask harnessbridge`.
HarnessBridge is ad-hoc signed (not notarized); see the caveats printed by Homebrew.
